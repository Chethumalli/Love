### ❤️ Love Interactive Web Experience

Welcome to Love — a fun, interactive web experience built with HTML, CSS & JavaScript! This project lets users explore playful interactions and animations around the theme of love. It’s light, responsive, and perfect for sharing with friends or using as a creative learning project.

🚀 Features

✨ Modern, responsive UI with smooth CSS styles
💕 Interactive pages that respond to user actions
🎵 Fun animations and playful design elements
📱 Works in all modern web browsers
📂 Simple structure — easy to customize and extend

📁 What's Inside
| File                               | Purpose                           |
| ---------------------------------- | --------------------------------- |
| `index.html`                       | Main landing page                 |
| `yes.html`                         | “Yes” response page               |
| `no1.html`, `no2.html`, `no3.html` | Different fun “No” outcomes       |
| `style.css`                        | All custom styles and layout      |
| `script.js`                        | JavaScript logic for interactions |
